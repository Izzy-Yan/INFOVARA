# INFOVARA — Autonomous AI-Powered Media Platform

# AI-driven media website that autonomously discovers trending topics, analyzes verified information from multiple sources, and publishes neutral, professionally written articles across categories such as technology, entertainment, science, gaming, business, and world events.

# The goal is to provide a modern, unbiased, fact-driven alternative to traditional news and tutorial websites.

# Core Features

# Automatic trend detection across major platforms

# Legal, safe, multi-source data collection

# Fact-verification and citation engine

# AI-generated articles using structured templates

# Category-based automated publishing

# Neutral, professional writing tone

# Admin dashboard for review, moderation, and analytics

# Tech Stack

# Backend: Python (FastAPI)

# Frontend: Next.js + Tailwind

# Database: Supabase (PostgreSQL)

# Hosting: Render / Vercel (free tiers)

# AI Models: Together AI (Llama 3.1) + fallback models

# Automation: Cron jobs, GitHub Actions, server schedulers

# Branching Strategy

# main — production

# dev — development

# feature/* — one branch per feature

# Contribution Rules

# Create a new branch for every feature.

# Use descriptive commit messages.

# All PRs must merge into dev.

# Only tested, clean code merges into main.

# Follow Python PEP8 formatting.
